# M8.7 — Revelation Engine: consolidation and constitutional closure

Status: implemented (pending local Mac validation). See
`docs/decisions/0018-revelation-engine.md` (amended for M8.7), the M8 Definitive
Specification (§9.1 invariants, §3.2 endpoint rule, §4 no-metric), and the M8
Engineering Blueprint. This is the **final milestone of M8**. It is **not** a
seventh revelation capability.

## What this is

M8.1–M8.6 built the six revelation lenses one at a time. M8.7 treats them as a
single Revelation Engine and **reviews, consolidates, hardens, and formally
closes** it. No new capability is added (no C7, no comparison lens, no
interpretation, no graph console); the emphasis is the constitutional audit and a
small, deliberate set of concrete improvements. The full audit and rationale are
in the engineering report; this note summarises the changes.

## The one production correction — pathway determinism (C6)

`reveal_person_pathway` chose its single minimal chain by `order by depth,
path_key`, and the `path_key` was built from the traversed **node** sequence only.
When two distinct assertions connect the same node pair (e.g. a person with two
documented participation periods at one institution), the competing chains shared
an identical ordering key, so the tie was broken by physical/plan order — the
returned chain, and the exact record each step decomposed to, was
**non-deterministic**. A new **append-only** migration
(`20260817090000_close_revelation_engine.sql`) folds each edge's canonical source
id into the path key, making the ordering **total**: the minimal chain is now
chosen by depth, then the node sequence, then each edge's stable assertion id — a
neutral identifier, never a metric. Reproduced-then-fixed in a disposable Postgres
16; the historical M8.6 migration is untouched.

## The one parser hardening — recurrence never fabricated

A recurrence group is now deduplicated by canonical source id before the ≥ 2 test,
so a duplicated occurrence (e.g. an upstream JOIN fan-out) can never manufacture —
or inflate the count of — a recurrence from a single record. This closes the one
place a malformed revelation could have become a false statement rather than an
honest absence.

## Consolidations (one deliberate engine, not six)

- **Evidence-contract parsers.** The provenance envelope and the source-ref
  pointer — the two shapes that carry the engine's decomposability contract — were
  hand-parsed identically in six and five places. They are now single
  `parseProvenance` / `parseSourceRef` primitives in `parse-shared`, so the
  contract cannot drift between lenses.
- **Reading primitives.** The identical provenance footer (verification badge +
  affordance) and node doorway that every lens re-declared inline are now two
  shared components, `RevealedProvenanceFooter` and `NodeDoorway`, with
  byte-identical output.

## Constitutional closure test

A single, total sweep (`revelation-constitutional-closure.test.ts`) asserts the
**whole** engine's reader-facing surface — every string in `revelationCopy` and
every `describe*` derivation output — is free of the forbidden interpretive frames
(similarity/metric/prestige tokens, and affirmative endpoint/ranking assertions),
while respecting the copy's honest negations ("not a connection", "never ranked",
"never scored by length"). This replaces six divergent per-operator checks with
one single-sourced guarantee, and includes a corpus-anchor guard so it can never
pass vacuously.

## Test robustness

The M8.1 cohort e2e now scopes its member assertions to the cohorts section (as
every other revelation spec does), while keeping the "a stranger never appears"
assertion page-global (strictly stronger). Two pgTAP assertions were added to the
pathway suite (plan 24 → 26) pinning the parallel-edge tie-break.

## Deferred and next (recorded, not built)

Comparison (**C5**) remains a deferred, enabled affordance, never assigned.
Interpretation is **M9**'s. Two architectural milestones are ratified as the next
work before M9 and are **not** designed or built here: **Projects as First-Class
Historical Actors** and the **Historical Operators Architecture**.

## Rejected changes (reviewed, deliberately not made)

A shared SQL node-projection helper (cosmetic, with a hot-path cost); a `person`
node on `reveal_person_cohorts` (no consumer); a `RevelationSection` wrapper (the
eight sections differ enough that a wrapper would lose per-lens clarity;
e2e/axe-certified only); re-ordering the institution page; changing revelation
heading weights; and an e2e page-quality helper (un-runnable here). Each is
recorded with its rationale in the engineering report.

## Tests

33 closure-sweep assertions + 2 recurrence-dedupe). Pathway determinism:
